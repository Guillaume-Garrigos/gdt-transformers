# Information on how to run this repo / website

## Turn the repo into a proper website

1. Settings > Pages > Branch > Select a branch (likely to be 'main') > Save
2. Done. Think about checking that the page is online. You should add a link to the website into the readme, to be able to easily navigate between the rendered website and the github repo.

# Misc.

## How to share a calendar

There is a way for participants to see your events on their calendar, with live updates.
More info at [https://support.google.com/calendar/answer/37100](https://support.google.com/calendar/answer/37100)

1. What the calendar owner must do
  - create a dedicated calendar for your events
  - Open Settings and sharing for your chosen calendar.
  - Check the box for Make available to public under Access permissions for events (note that this lets anyone view it).
  - Scroll down to Integrate calendar.
  - Copy the Public address in iCal format link to share with others so they can subscribe to live updates.
  - Share the .ical link on your website. Maybe add a link to the above Google support page for instructions.
2. What the participants can do
  - Copy the said link (downloading the ical file is useless)
  - In the left sidebar, scroll down to the Other calendars section.
  - Click the + (Add other calendars) button right next to it.
  - Select From URL from the dropdown menu.
  - Paste the iCal link (the address ending in .ics) into the field.
  - Click Add calendar.
